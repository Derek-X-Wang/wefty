## M3 §10 amendment verdict

A Computer remains an L1 resource and reconfiguration projects an immutable
service Job on the same identity/Storage; it does not create an L3 Run.
[The agent strips tenant reserved values](../../agent/attempt_lifecycle.go#L1304),
mints only the Computer pass, and selects the
[Computer bridge separately from the one-shot bridge](../../agent/attempt_lifecycle.go#L1711).
[No-Run identity tests](../../l1/run_identity_entitlement_test.go#L270) cover
creation, projection and import. [Reserved-value stripping](../../agent/workload_runtime_test.go#L713)
plants a Run token and checks it is removed; [enabled/default-off delivery](../../agent/workload_runtime_test.go#L766)
covers the Computer pass. Image environment is stripped again by the helper's
[reserved-layer construction](../../runner/ocihelper/profile.go#L803).

`TestComputerReferenceImagesStayOptional` in the
[new guard](../../scripts/computer_reference_scope_contract_test.go#L12) pins both
README disclaimers and the contract restriction, and rejects literal reference
repositories/example paths in non-test product Go and non-Computer example
Dockerfiles, including ARG substitutions. Appending
`FROM ghcr.io/derek-x-wang/wefty-computer-reference:planted-violation` to
`examples/oci-echo-service/Dockerfile` failed at test line 48 in
`run_a86ed20cada0db6e7f4bbdb8e8d71583` (7.619 s, payload exit 1/CLI exit 10).
Restoration preserved SHA-256 `cd619360cfd728baa976667b465b5cf018479f0b802b5c3053e9d4be30855109`.
The inspected
[CLI resolver](../../cmd/wefty/computer_command.go#L115) requires the caller's
image, and [runtime helper inputs](../../runner/oci/adapter.go#L2802) preserve
that identity. This is a bounded automated source proof of
`no_generic_oci_base_claim`; third-party derivations are outside its scope.
No historical or hardware row is upgraded here.

## Distinct removal proofs and limits

- `removed_verified`: the [native lane](../../serviceacceptance/computer_realtiming_test.go#L811)
  creates an untainted Computer, removes it through the CLI and independently
  inventories the helper; Mac run 6 reports the attended equivalent PASS.
- Computer-only `removed_reduced`: the same lane binds the
  [reduced outcome to the tainted import](../../serviceacceptance/computer_realtiming_test.go#L859);
  [clone/coordinated removal](../../l1/storage_copies_integration_test.go#L878)
  and [export/attestation](../../l1/custody_integration_test.go#L400) distinguish custody truth.
- `forgotten_cleanup_unverified`: [real CLI/L1 routes](../../cmd/wefty/service_command_test.go#L492)
  exercise force-forget for an ordinary service, assert
  [JSON and permanent table wording plus the standing directive](../../cmd/wefty/service_command_test.go#L575).
  This is not a Computer end-to-end waiver proof: current
  [Computer-owned Job policy refuses `forget`](../../l1/service_operator.go#L134)
  ([contract](../contracts/state-machines.md#L1755)).
  [#462's regression](../../l1/removal_integration_test.go#L740) plants a
  Computer waiver directly in the store. Its late-cleanup proof must not be
  described as a public Computer waiver path. The later
  [#462 resolution](https://github.com/Derek-X-Wang/wefty/issues/462#issuecomment-5727335181)
  fixes only late finalization. [#450's explicit future-waiver note](https://github.com/Derek-X-Wang/wefty/issues/450#issuecomment-5727140593)
  requires distinct outcome/custody rendering, waived wait/result handling and
  real-path tests before enabling it. No later enabling ticket or ADR was found
  in the `Computer waiver`, `Computer forget` and `Computer force-forget`
  issue searches plus the ADR review. [ADR-0002](../adr/0002-hygiene-beats-availability.md#L38)
  defines the general waiver rule but does not enable a Computer endpoint.
  Thus #196 cannot claim Computer-waiver end-to-end proof; the older spec
  promise is qualified by that later deferral, not a reason to add behavior here.

No inspected public renderer upgrades reduced custody or an unverified Job to
clean: [Computer output carries a separate removal column](../../cmd/wefty/computer_command.go#L724),
[stalled cleanup is rendered explicitly](../../cmd/wefty/computer_command_test.go#L1058),
and [API/docs separate Job outcome from custody](../contracts/state-machines.md#L683).
The two claims must be read together, even when late cleanup proves custody
absence after an unverified Job outcome.
